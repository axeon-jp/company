## 「スキルがあれば年収は上がる」は半分正解、半分間違い

ITエンジニアの転職市場は売り手市場が続いている。しかしスキルがあれば自動的に年収が上がるわけではない。

年収600万円のエンジニアが転職しても650万円にしかならない人と、同じスキルで800万円のオファーを得る人がいる。

この差を生むのはスキルではなく、**転職の進め方**だ。

---

## 年収が上がらない転職でよくある失敗

### 失敗1: 現職の年収を基準に交渉している

「現職が600万円なので620万円希望です」という交渉は、現職年収を上限に設定してしまう。

市場価値を基準に交渉することで、現職より大幅に高いオファーを引き出せるケースがある。

### 失敗2: 大手企業に絞りすぎている

知名度のある大手に絞ると、競争率が高く・選考が長く・年収レンジが硬直していることが多い。

成長中のメガベンチャーやスタートアップは、技術力があるエンジニアに対して大手を上回るオファーを出すことがある。

### 失敗3: 転職エージェントを使わない、または一社だけ使う

転職エージェントは使わないと求人へのアクセスが制限される。同時に複数のエージェントを使うことで、各社の求人の幅が広がり、オファーを比較できる。

---

## ハイクラス転職と一般転職の違い

年収800万円以上のポジションは、一般の転職サイトでは流通しにくい。非公開求人として特定のエージェントにのみ提供されることが多い。

ハイクラス転職専門のエージェントを使う理由はここにある。

一般転職: 公開求人 → 応募 → 選考  
ハイクラス転職: 非公開求人 → スカウト / 紹介 → 選考

アプローチのルートが違うため、見える求人の質と数が変わる。

## ITエンジニアの市場価値が高い分野

需要が高く、年収レンジが上がりやすいスキルセット：

**クラウド・インフラ系**
- AWS / GCP / Azure の設計・運用経験
- Kubernetes / Terraform

**バックエンド・アーキテクチャ系**
- 大規模トラフィックの設計経験
- マイクロサービスアーキテクチャ

**AI・データ系**
- LLM / RAG の実装経験
- MLOps / データパイプライン

これらの経験を持つエンジニアは、転職市場での交渉力が高い。

## 転職活動のタイムライン

| 期間 | やること |
|------|---------|
| 1〜2週間 | エージェント登録・職務経歴書の整備 |
| 2〜4週間 | 求人の選定・応募 |
| 1〜2ヶ月 | 選考・面接 |
| 内定後 | 年収交渉・入社日調整 |

在職中の転職は2〜3ヶ月が標準的なスケジュールだ。

## 転職を成功させるための準備

**職務経歴書の質が採用を左右する**

技術スタックを列挙するだけでは不十分。「何を・どのように解決したか」「規模・チームでの役割」を具体的に書く。

**ポートフォリオの整備**

GitHubのコード品質、アウトプットの公開は、特に若手エンジニアの評価材料になる。

**逆質問の準備**

「この会社で何を実現したいか」「技術的な課題を教えてほしい」など、質の高い逆質問は志望度と理解度を示す。
