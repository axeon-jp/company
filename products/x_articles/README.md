# X Articles

## ディレクトリ構成

```
x_articles/
├── original/   X専用オリジナル記事（収益シェア狙い）
└── affiliate/  アフィリエイト記事（リンク誘導で収益化）
```

## ファイル命名規則

`01_記事タイトル_slug.md` — note_articlesと同じ連番形式

## 価格・公開設定

- original: 無料公開（X収益シェアで回収）
- affiliate: 無料公開（アフィリエイトリンクで回収）

## 品質基準

- 最低1,000語（アルゴリズム評価の基準）
- noteと同テーマでも別視点・別構成で書く
- アフィリエイトリンクは末尾に1〜2個まで（#PR表記必須）
