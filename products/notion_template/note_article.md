## 📅 投稿カレンダー — 詳細

投稿カレンダーはNotionのデータベースで構築しています。

**カレンダービューとテーブルビューを切り替えて使います。**

### プロパティ一覧

| プロパティ | 種類 | 使い方 |
|---|---|---|
| 投稿内容 | タイトル | ツイート本文をそのまま入力 |
| 投稿日時 | 日付 | 予約投稿する日時 |
| ステータス | セレクト | 📝下書き→✅承認済→🚀投稿済 |
| 投稿タイプ | セレクト | 教育系/共感系/裏側系/告知/リプライ |
| エンゲージメント予測 | セレクト | 🔥高/📊中/💤低（投稿前に予測） |
| 実績いいね数 | 数値 | 投稿後に記録 |
| 実績RT数 | 数値 | 投稿後に記録 |
| 実績インプレッション | 数値 | 投稿後に記録 |

### 使い方のポイント

**週の始めにやること：**
1. その週に投稿する内容を「下書き」ステータスで作成
2. 投稿日時を設定してカレンダービューで確認
3. AIで生成した文をそのままタイトル欄に貼り付けでOK

**投稿後にやること：**
1. ステータスを「投稿済」に変更
2. いいね・RT・インプレッションを記録
3. 数字が良ければ「バズ研究」ページにも転記

## 💡 ネタストック — 詳細

ネタが思いついたときにすぐ保存する場所です。

### プロパティ一覧

| プロパティ | 種類 | 使い方 |
|---|---|---|
| ネタタイトル | タイトル | 一言でネタの内容を書く |
| カテゴリ | セレクト | 教育系/共感系/裏側系/バズ狙い |
| ステータス | セレクト | 🌱アイデア→📝下書き中→✅使用済 |
| 参考URL | URL | 参考にしたツイートや記事 |
| メモ・着想 | テキスト | ネタの方向性・書きたいこと |
| 優先度 | セレクト | 🔴高/🟡中/🟢低 |

### 使い方のポイント

ネタは**思いついた瞬間に入力**するのが鉄則です。

スマホからNotionを開いて、タイトルだけ入れるだけでOK。
あとでPCで肉付けします。

ギャラリービューに切り替えると**カード形式で一覧**できて、ストックの全体像が見やすくなります。

**ネタが枯渇したときは：**
後述の「AIプロンプト集」にある「ネタ30個出し」プロンプトをそのまま使ってください。一気に補充できます。

## 📊 週次レポート — 詳細

毎週末（日曜夜）に5分で記録します。

### プロパティ一覧

| プロパティ | 種類 |
|---|---|
| 週（例: 2026年W17） | タイトル |
| 期間 | 日付（範囲） |
| フォロワー数（週末時点） | 数値 |
| フォロワー増加数 | 数値 |
| 総いいね数 | 数値 |
| 総RT数 | 数値 |
| 総インプレッション | 数値 |
| 投稿本数 | 数値 |
| 平均エンゲージメント率 | 数値（%） |
| 今週のMVP投稿 | テキスト |
| 来週の改善点 | テキスト |

### エンゲージメント率の自動計算フォーミュラ

Notionのフォーミュラプロパティに以下を入力すると、自動計算されます。

```
prop("総いいね数") / prop("総インプレッション") * 100
```

### 週次レビューのやり方

記録が終わったら、以下のAIプロンプトに数字を貼り付けて振り返りをします（後述のプロンプト集に収録）。

```
先月のX投稿を振り返って、改善アドバイスをください。
総投稿数：[本数]
平均インプレッション：[数]
最も反応が多かった投稿：[内容]
...
```

## 🏆 バズ研究 — 詳細

「なぜこの投稿はバズったのか」を分析して、自分の投稿に応用するページです。

### プロパティ一覧

| プロパティ | 使い方 |
|---|---|
| 投稿タイトル | バズった投稿の内容を一言で |
| 元ツイートURL | 参照元のURL |
| いいね数・RT数 | 実績数値 |
| バズった理由（分析） | なぜ伸びたかを自分で分析 |
| 自分への応用メモ | 自分のアカウントに活かすには？ |
| カテゴリ | 教育系/共感系/裏側系 |

### 分析フレーム（コピペして使う）

バズ研究ページのメモ欄に以下を貼り付けて分析します。

```
【バズった理由を分析してください】

ツイート内容：[ツイートを貼り付け]
いいね数：[数] / RT数：[数]

分析してほしい観点：
1. 最初の1行の引きの強さ
2. 構成（箇条書き・改行・長さ）
3. 感情に訴えているポイント
4. 私のアカウントで同じ構造を使うなら？
```
