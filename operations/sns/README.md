# SNS運用オペレーション

## クライアント管理

各クライアントのファイルを `clients/[クライアント名]/` に作成する。

```
operations/sns/
├── clients/
│   └── [クライアント名]/
│       ├── profile.md        # クライアント情報・目標・トンマナ
│       ├── accounts.md       # 運用するSNSアカウント一覧
│       ├── content_plan.md   # 月次コンテンツカレンダー
│       └── reports/          # 月次レポート
├── templates/                # 投稿テンプレート集
└── sop/                      # 標準オペレーション手順
```

## 投稿フロー (AI自動化)

```
1. コンテンツカレンダーから今日の投稿テーマを取得 (COO)
2. AIがドラフト生成 (CTO管轄のコンテンツ生成エージェント)
3. クライアントのトンマナチェック (自動)
4. スケジュール投稿 (SNS API経由)
5. エンゲージメント計測 → 週次レポートに反映 (CMO)
```
