# コンテンツ生成オペレーション

## AIコンテンツパイプライン

```
[テーマ・キーワード入力]
        ↓
[リサーチエージェント] → トレンド・競合投稿の調査
        ↓
[ライティングエージェント] → 投稿文の生成（複数バリエーション）
        ↓
[トンマナチェック] → クライアントのガイドラインと照合
        ↓
[ビジュアル生成] → 画像・グラフィックの生成（必要な場合）
        ↓
[スケジュール登録] → 最適な投稿時間帯に自動投稿
```

## コンテンツタイプ

| タイプ | 説明 | 担当AI |
|--------|------|--------|
| 教育系 | ノウハウ・Tips・解説 | ライティングエージェント |
| 告知系 | キャンペーン・お知らせ | CMO |
| エンゲージメント系 | 質問・アンケート・共感 | ライティングエージェント |
| UGC活用 | 顧客の投稿リポスト | COO |
