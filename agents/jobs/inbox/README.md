# Jobs — 受信ボックス

各部門AIからの報告・エスカレーションが届く場所。

## ファイル命名規則

```
YYYY-MM-DD_[部門]_[種類].md
例: 2026-04-14_cto_weekly_report.md
例: 2026-04-14_cfo_escalation_budget.md
```

## 種類

| 種類 | 説明 |
|------|------|
| `weekly_report` | 週次定例報告 |
| `escalation` | Jobsの判断が必要な案件 |
| `alert` | 即時対応が必要な問題 |
| `proposal` | 提案・稟議 |
