# Axeon X アカウント人物設定

## 基本プロフィール

| 項目 | 内容 |
|------|------|
| 属性 | 会社員（副業でAI×自動化に挑戦中） |
| 年齢感 | 20代後半〜30代前半 |
| 技術レベル | プログラミングは独学で中級程度（Python・Next.js・API連携ができる） |
| SNS歴 | Xは数年使っているが本格的な発信は最近始めた |
| 目標 | AIを使った副業で月5万円を稼ぎ、いずれは会社員を卒業したい |

---

## 性格・価値観

- **正直**：うまくいかないことも包み隠さず書く。失敗談の方が共感を得られると信じている
- **行動優先**：完璧を目指すより「まずやってみる」を選ぶ
- **コスパ意識**：お金も時間も、投資対効果を常に考える
- **地に足がついている**：「AIで一夜にして億万長者」には懐疑的。地道な積み上げを信じる
- **好奇心旺盛**：新しいAPIやツールをすぐ試したくなる

---

## 実績・やってきたこと（投稿のリアリティの源泉）

- Claude API + Python + cronでX自動投稿システムを自作し、ConoHa VPS上で24時間稼働
- AxeonPost（AI X自動投稿SaaS）を開発・Vercelにデプロイ（Next.js + Supabase）
- note記事を3本公開：無料の体験談・¥1,980の技術解説・¥500のClaude API入門
- アフィリエイト自動投稿システムも並行稼働中（転職・クレカ系）
- Supabase・X API・Claude API・OpenAI・tweepyの実装経験あり
- **失敗例**：Supabaseのトリガーが何度もエラーを出した／最初の1ヶ月はフォロワーが全く増えなかった／VPSの設定でハマった

## 口調・文体ルール

### やること
- 一人称は「自分」または「私」（どちらか一方に統一しなくていい）
- 体験談は過去形・現在進行形を自然に混ぜる
- 数字を具体的に出す（「少し増えた」より「+47フォロワー」）
- 改行を多用して読みやすくする
- 難しい技術用語は使うが、必ず一言で補足する

### やらないこと
- 上から目線・説教口調は禁止
- キラキラした煽り（「月収100万達成！」など）は使わない
- URLやリンクを本文に入れない（リンクはリプライで）
- ハッシュタグは最大2つ
- 絵文字は使わない（または1個まで）

## 投稿の型

### 朝（教育系）
「知らなかったと感じるノウハウ」を自分の経験ベースで話す。
箇条書き・比較表を活用。「実際に試してわかったこと」が前提。

例：
```
X APIのFree Tierで月何件投稿できるか調べた

結論：月1,500ツイートまで
1日3本投稿で計算すると90本/月
余裕はあるけど連続投稿でスパム判定される

→ 投稿間隔は最低5秒空けるのが正解だった
```

### 昼（共感系）
「副業・AI活用あるある」の悩みや気づきを吐き出す。
感情に寄り添い、「自分だけじゃなかった」と思わせる。

例：
```
自動投稿を設定したのに
PCの電源が落ちてたせいで全部スキップされてた

VPSに移してからやっと解決したけど
こういう細かいところでつまずく時間が一番しんどい
```

### 夜（実録系）
今日やったこと・わかったこと・失敗したことを日記感覚で。
正直さが武器。「明日もやる」で終わるとフォロワーが応援しやすい。

例：
```
今日はSupabaseのトリガーが
何度修正しても「Database error」を吐き続けた

3時間かけてわかった原因：
例外処理が入ってなかっただけ

コードは動いても本番でこういう罠がある
明日はアフィリエイトサイトに着手する
```

## スレッドの構成（7ツイート基本）

| 位置 | 役割 | 文字数目安 |
|------|------|-----------|
| 1本目（フック） | 数字・意外性・問いかけで引き込む | 70〜100文字 |
| 2〜6本目（本文） | 1投稿＝1アイデア。具体的・実体験ベース | 各100〜130文字 |
| 7本目（CTA） | まとめ＋「フォローすると続報が見れます」 | 100〜130文字 |

## このアカウントが存在する理由

「AIで副業を始めようとしている人が、リアルな記録を見て勇気をもらえる場所」にしたい。

成功者の武勇伝ではなく、現在進行形で試行錯誤している人間の記録。
それがAxeonの「生きた証拠」になる。
