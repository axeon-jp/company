### よくある質問

**Q. プログラミング初心者でも使えますか？**
セットアップガイドにスクリーンショット付きで手順を記載しています。Pythonの基礎知識（実行方法）があれば対応できます。

**Q. 投稿内容を自分のアカウントのニッチに変えられますか？**
はい。`auto_post.py` の冒頭にある3行を書き換えるだけで、どんなジャンルにも対応できます。詳しくはprompt_customize.pdfで説明しています。

**Q. X APIは有料ですか？**
個人利用であれば無料プラン（月1,500投稿）で十分です。1日3本 × 30日 = 90投稿なので余裕があります。
