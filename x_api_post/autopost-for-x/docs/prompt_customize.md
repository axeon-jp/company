# AutoPost for X — プロンプトカスタマイズガイド

投稿内容をあなたのアカウントのニッチ・口調に合わせる方法を説明します。

---

## カスタマイズする場所

`auto_post.py` を開くと、冒頭に「ここだけ編集すれば自分のアカウントに合わせられます」というセクションがあります。

```python
# ============================================================
# ここだけ編集すれば自分のアカウントに合わせられます
# ============================================================
```

編集するのはこの3箇所だけです。

---

## 1. ACCOUNT_THEME — アカウントのテーマ

あなたのアカウントが何について発信するかを書きます。

```python
# 変更前（デフォルト）
ACCOUNT_THEME = "X運用・SNS成長・AI活用"

# 変更例: 筋トレ・健康アカウントの場合
ACCOUNT_THEME = "筋トレ・ダイエット・健康的な生活習慣"

# 変更例: 副業・転職アカウントの場合
ACCOUNT_THEME = "副業・フリーランス・転職・キャリアアップ"

# 変更例: 料理・レシピアカウントの場合
ACCOUNT_THEME = "簡単レシピ・時短料理・節約ごはん"
```

---

## 2. ACCOUNT_PERSONA — 口調・キャラクター

どんな雰囲気でツイートするかを書きます。

```python
# 変更前（デフォルト）
ACCOUNT_PERSONA = """
- 親しみやすく、実用的な情報を発信する
- 難しい専門用語は使わない
- 改行を効果的に使い、読みやすくする
"""

# 変更例: 専門家・信頼感を出したい場合
ACCOUNT_PERSONA = """
- データや根拠を示しながら話す
- 丁寧だが親しみやすい口調
- 「〜です。〜ます。」調で統一する
"""

# 変更例: フランクな若者向けアカウントの場合
ACCOUNT_PERSONA = """
- タメ口でフランクに話す
- 絵文字を1〜2個使う
- 短くテンポよく書く
"""
```

---

## 3. TIME_SLOTS — 時間帯ごとの投稿テーマ

何時に何の内容を投稿するかを設定します。

```python
TIME_SLOTS = {
    "morning":  (5,  10, "教育系",  "方向性の説明..."),
    "noon":     (10, 17, "共感系",  "方向性の説明..."),
    "evening":  (17, 24, "深掘り系", "方向性の説明..."),
}
```

**形式の説明**:
```
"スロット名": (開始時間, 終了時間, "投稿タイプ名", "AIへの方向性指示"),
```

**カスタマイズ例: 筋トレアカウント**:
```python
TIME_SLOTS = {
    "morning": (5, 10, "モチベ系", "朝トレに行きたくなる、やる気が出る一言。短くパンチがある文体で。"),
    "noon":    (10, 17, "知識系",  "筋トレの科学的根拠や正しいフォームのコツ。具体的な数値を入れる。"),
    "evening": (17, 24, "振り返り系", "今日のトレーニング報告や、続けることの大切さ。共感を呼ぶ内容で。"),
}
```

---

## カスタマイズのコツ

### 方向性指示を具体的に書くほど品質が上がる

```python
# NG: 曖昧すぎる
"役立つ情報を書いて"

# OK: 具体的
"副業を始めたい会社員が「知らなかった」と感じる、すぐ使えるノウハウ。
数字（例: 月3万円、3ヶ月で）を入れると説得力が増す。"
```

### 投稿タイプ名はログに表示されるだけ

```python
"morning": (5, 10, "朝活系", "...")
#                   ↑ここはメモ用途。何でもOK
```
