# SNSプラットフォーム別ナレッジ

各プラットフォームの特性・API情報・ベストプラクティスを蓄積する。

## ファイル構成

```
platforms/
├── x.md           # X (Twitter)
├── instagram.md   # Instagram
├── tiktok.md      # TikTok
├── youtube.md     # YouTube
└── linkedin.md    # LinkedIn
```

## 共通チェック項目（各プラットフォームファイルに記載）

- 文字数制限
- 画像・動画スペック
- 投稿最適時間帯
- アルゴリズムの特性
- API制限・レート制限
- 広告ポリシー上の注意点
