# X (Twitter) プラットフォームナレッジ

## 基本スペック

| 項目 | 内容 |
|------|------|
| 文字数制限 | 280文字（無料）/ 25,000文字（Premium） |
| 画像 | 最大4枚、JPG/PNG/GIF/WEBP、5MB以下 |
| 動画 | 最大2分20秒（無料）、最大10分（Premium） |
| リンク | 23文字として換算 |

## アルゴリズムの特性

- **エンゲージメント優先**: いいね・リポスト・リプライ・クリックが多い投稿が拡散
- **投稿直後の初速が重要**: 最初の30〜60分の反応が拡散を左右する
- **プレミアムユーザーの投稿は有利**: リプライ欄で上位表示
- **長文は収益化ユーザーに有利**: スレッドより単体投稿が読まれやすい傾向

## 投稿最適時間帯（日本）

| 時間帯 | エンゲージメント傾向 |
|--------|------------------|
| 7:00〜9:00 | 通勤時間帯、高め |
| 12:00〜13:00 | 昼休み、高め |
| 21:00〜23:00 | 夜間、最も高い |
| 深夜0:00〜 | 一部層にリーチ |

## 一般人向けX運用の戦略

### フォロワーを増やすには
1. **ニッチを絞る** — 「何の人」か明確にする
2. **毎日投稿** — 最低1日1〜3投稿
3. **バズ投稿の型** — 共感・驚き・役立つ情報・論争（ただし炎上注意）
4. **インフルエンサーへのリプライ** — 有名アカウントの投稿に質の高いリプライ
5. **スレッド（長文）** — 専門知識・体験談の深掘り

### コンテンツの型（一般人向け）
- **体験談型**: 「〇〇してみた結果」
- **まとめ型**: 「〇〇について知っておくべき5つのこと」
- **共感型**: 「〇〇あるある」
- **論破型**: 「実は〇〇は間違い」（議論を呼ぶ）
- **日常型**: リアルな日常 + 学び・気づき
