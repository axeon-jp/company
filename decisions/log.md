```

- **決定者**: Jobs / Owner
- **背景**: なぜこの決定が必要になったか
- **選択肢**: 検討した選択肢
- **決定内容**: 何を決めたか
- **理由**: なぜそれを選んだか
- **期待する結果**: これにより何が変わるか
```

## [2026-06-22] 製品方針の転換：ツール販売から完全代行サービスへ

- **決定者**: Owner（Jobs合意）
- **背景**: X Post Scheduler（Electron app）をGumroadで販売したが売上0。原因を分析した結果、製品のターゲット（ある程度のITリテラシーが必要なユーザー）とAxeonが本来狙うべきターゲット（ITリテラシーが低い一般人）が根本的にずれていることが判明
- **決定内容**:
  - 今後、ソフトウェアツール（デスクトップアプリ・スクリプト等）の新規開発・販売は行わない
  - 製品の軸を「ツールを売る」から「結果（フォロワー増加・X運用）を売る完全代行サービス」に統一する
  - 既存のX Post Scheduler（Gumroad出品済み）は放置。追加開発リソースは投下しない
  - 今後の収益化はnote記事＋サービス申し込み導線に統一する
- **理由**: Axeonのミッションは「一般の人が情報発信でき、フォロワーと影響力を着実に伸ばす手助けをする」こと。ITリテラシーを前提とするツールはこのミッションと矛盾する。「申し込んだら勝手に動く」体験だけを提供する
- **期待する結果**: ターゲット層との整合性が取れ、パイロット顧客獲得・サービス設計の方向性が明確になる

## [2026-04-21] 収益モデルの変更: サブスク → 高単価アフィリエイト成果報酬型

- **決定者**: Owner（Jobs推薦）
- **背景**: サブスク型（¥980/月）では一般人ターゲットの獲得が難しく、価値提案が曖昧。成果報酬型に転換することで「稼がせる」という具体的な価値提案に変更。
- **決定内容**:
  - 収益モデル: クライアントのXアカウントで高単価アフィリエイト投稿を代行し、発生した成果報酬の **20%** をAxeonが取る
  - アフィリエイト商材: Axeonが選定（A8.net / ValueCommerce等の高単価ASP経由）
  - 対象ジャンル: 絞らない（ただし金融系は法規制対応を必須とする）
  - 高単価カテゴリ優先: クレカ・証券口座・転職・オンラインスクール等（成果単価¥5,000〜¥50,000）
- **理由**: Amazon等の低単価商材（Axeon取り分¥54〜¥270/月）では事業が成立しない。高単価商材に絞ることで1クライアントあたり月¥5,000〜¥50,000の収益が見込める
- **期待する結果**: クライアント10人でMRR ¥50,000〜¥150,000
- **要対応事項**:
  - ステマ規制（#PR明示）のCTO実装組み込み
  - 金融商品取引法の広告規制対応
  - X APIのアフィリエイトリンク投稿に関するアルゴリズムリスクの実測
