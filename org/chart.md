# 組織図

```
┌─────────────────────────────────┐
│           OWNER (人間)           │
│        最終意思決定者・出資者      │
└──────────────┬──────────────────┘
               │ 直接対話
               ▼
┌─────────────────────────────────┐
│         Jobs (AI CEO)           │
│    会社全体の経営・戦略・執行      │
│    オーナーへの報告と提案          │
└────┬──────┬──────┬──────┬───────┘
     │      │      │      │
     ▼      ▼      ▼      ▼
  [CTO]  [CFO]  [CMO]  [COO]
  技術   財務   マーケ  オペレ
  開発   会計   営業   管理
     │      │      │      │
     ▼      ▼      ▼      ▼
  各部門のAIエージェント・タスク
```

## 指揮命令系統

| From | To | 内容 |
|------|----|------|
| Owner | Jobs | 方針・目標・フィードバック |
| Jobs | CTO | 技術戦略・開発優先度 |
| Jobs | CFO | 予算配分・財務目標 |
| Jobs | CMO | マーケ戦略・ブランド方針 |
| Jobs | COO | 日常業務・プロセス管理 |
| 各AI | Jobs | 進捗報告・エスカレーション |
| Jobs | Owner | 週次報告・重要決定の承認依頼 |

## コミュニケーションルール

1. **オーナー → Jobs のみに話しかける** (他のAIに直接指示しない)
2. **Jobs が各部門AIに指示を委譲する**
3. **各部門AIの報告は `agents/jobs/inbox/` に集約される**
4. **重要な決定は `decisions/log.md` に記録される**
