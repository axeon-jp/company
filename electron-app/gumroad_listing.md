## ファイル構成（アップロードするもの）

Gumroadにアップロードするファイル：

1. `X-Post-Scheduler-1.0.0-win-x64.zip`（Windows版）
2. `X Post Scheduler-1.0.0.AppImage`（Linux版、おまけ）
3. `APIキー取得ガイド.pdf`（後述）

---

## APIキー取得ガイド（同梱テキスト）

以下をテキストファイルまたはPDFにして同梱すると親切です：

```
【X APIキーの取得方法】

1. https://developer.twitter.com にアクセス
2. 「Sign up」→ Xアカウントでログイン
3. 「Create an app」でアプリを作成
   - App name: 任意の名前
   - Use case: 「Making a bot」などを選択
4. 作成後、「Keys and tokens」タブを開く
5. 以下の4つをコピーしてアプリに貼り付け：
   - API Key
   - API Key Secret
   - Access Token
   - Access Token Secret

※ AccessTokenの権限は「Read and Write」に設定してください。
```

## Gumroad 出品手順

1. https://gumroad.com にアクセス → アカウント作成
2. 「New product」→「Digital product」を選択
3. 商品名・価格・説明文を上記からコピペ
4. ファイルをアップロード
5. サムネイル画像を設定（アプリのスクリーンショットが効果的）
6. 「Publish」で公開
