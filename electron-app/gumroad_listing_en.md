## API Key Setup Guide (include in download)

```
X POST SCHEDULER — API KEY SETUP GUIDE
=======================================

You need 4 keys from X (Twitter) Developer Portal.
This takes about 5 minutes and is completely free.

STEP 1 — Create a developer account
  Go to: https://developer.twitter.com
  Click "Sign up for Free Account"
  Log in with your X account

STEP 2 — Create an app
  Click "Create Project" or "Add App"
  App name: anything you like (e.g. "My Scheduler")
  Use case: select "Making a bot" or "Automating posts"

STEP 3 — Set permissions
  Go to your app settings → "User authentication settings"
  Set permissions to "Read and Write"
  (Required for posting tweets)

STEP 4 — Get your keys
  Go to "Keys and tokens" tab
  Copy all four values:

    API Key              → paste into "API Key" field in the app
    API Key Secret       → paste into "API Key Secret" field
    Access Token         → paste into "Access Token" field
    Access Token Secret  → paste into "Access Token Secret" field

STEP 5 — Open the app
  Unzip the downloaded file
  Double-click "X Post Scheduler.exe"
  Click "API Settings" in the top-right corner
  Paste your 4 keys and click Save

You're ready to schedule posts.

NOTE: The free X API tier allows up to 500 tweets/month.
For most users this is more than enough.

Need help? Message via Gumroad.
```
