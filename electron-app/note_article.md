# X（旧Twitter）の投稿管理が劇的にラクになるアプリを作りました【無料で使えるAPIキー取得方法も解説】

毎日X（旧Twitter）に投稿しているけど、こんな悩みはありませんか？

- 「夜作った投稿を朝に出したいのに、起きてから投稿するのが面倒」
- 「スレッドを投稿するとき、手作業でリプライするのが手間」
- 「画像付きで予約投稿できるツールを探しているけど月額が高い」

そこで、**完全無料・買い切りで使えるデスクトップアプリ「X Post Scheduler」**を作って公開しました。

---

## X Post Schedulerとは

Windows上で動く**X（Twitter）専用の投稿管理アプリ**です。

**主な機能：**

- **予約投稿** — 指定した日時に自動でXへ投稿
- **スレッド投稿** — 複数ツイートをまとめてスレッド形式で連続投稿
- **画像添付** — 画像を選んでそのまま投稿に添付
- **下書き保存** — 日時を設定しなければ下書きとして保管
- **APIキー暗号化保存** — キーはPC内でOSレベルの暗号化をかけて保存。外部サーバーへの送信ゼロ

---

## 実際の画面

アプリは2カラム構成のシンプルなUI。

**左パネル**に投稿内容を入力して、**右パネル**で予約・下書き・投稿済みの一覧を管理できます。

- 通常投稿とスレッドはボタン一つで切り替え
- 投稿カードにはステータスバッジ（予約中 / 準備OK / 下書き / 投稿済み）を表示
- 投稿済みツイートは直接Xへのリンクが表示される

## セットアップは5分で完了

インストール不要。ZIPを解凍して `X Post Scheduler.exe` をダブルクリックするだけです。

### APIキーの取得方法

アプリを動かすにはX（Twitter）のAPIキーが必要です。無料で取得できます。

**手順：**

1. [developer.twitter.com](https://developer.twitter.com) にアクセス
2. 「Sign up for Free Account」→ Xアカウントでログイン
3. アプリを作成（App name は何でもOK）
4. 「Keys and tokens」タブを開く
5. 以下の4つをコピー：
   - API Key
   - API Key Secret
   - Access Token
   - Access Token Secret

> ポイント：Access Tokenの権限を「**Read and Write**」に設定するのを忘れずに。

取得したキーをアプリ右上の「API設定」ボタンから入力すれば完了です。

## なぜ作ったのか

自分自身がXを毎日運用していて、「**予約投稿のためだけに月数千円のサービスを使うのは割に合わない**」と感じていました。

そもそもXのAPIを直接使えば、同じことは無料でできます。でもコマンドラインで操作するのはハードルが高い。

→ だから、誰でも使えるGUIアプリとして作りました。

技術的な話をすると、Electron + twitter-api-v2 で構築。APIキーはOSのKeychainレベルの暗号化（Electron safeStorage）を使っているので、ファイルに平文で保存されることはありません。
